## Overview

DriveZone is a full-stack showroom management system developed using Java Servlets, JSP, MySQL, and Apache Tomcat.  
The platform centralizes dealership workflows including inventory handling, authentication, enquiry management, and customer interaction through a modern responsive interface.

---

## Core Features

- Secure Authentication & Session Management
- Vehicle Inventory Administration
- Customer Enquiry Processing
- Responsive Premium UI
- Role-Based Access Control
- Scalable MVC Architecture
